## Phase log

### Phase 0: scaffold, tooling, corpus, EmbedPDF spike

Built:

- Tauri 2 + React 19 + TS (strict + `noUncheckedIndexedAccess`,
  `exactOptionalPropertyTypes`) + Vite 8, from create-tauri-app (react-ts).
- Rust `fileio.rs`: `read_pdf` and `save_pdf_as` (temp file + atomic rename; refuses to
  overwrite the source; locked-file message on Windows). Tauri CSP blocks all network.
- Gates: `npm run check` = typecheck, ESLint, Prettier, Vitest, `cargo test`,
  license-check. Plus `npm run test:e2e` (Playwright).
- `scripts/license-check.mjs`: an SPDX evaluator over npm + `cargo metadata`, with
  policy in `license-policy.json`.
- Corpus: `tests/corpus/generate.mjs` (synthetic, regenerated by Vitest setup) and
  committed IRS 1040/W-9/8879.
- `src/engine/` (Node-safe; ESLint forbids React/DOM/Tauri): PDFium bootstrap, guarded
  text extraction, spike ops (stamp, free text, find, mark/apply redaction, save).
- Throwaway `#/spike` page (`src/spike/`), linked from the placeholder home page.

Deviations from spec:

- license-check is a custom script, not license-checker-rseidelsohn (5.x needs Node 24;
  exact-string matching misses SPDX variants).
- Step 4d test asserts "SSN absent everywhere", but EmbedPDF can't deliver that yet, so
  6 checks are `it.fails` (known gaps), per owner decision.
- Native-dialog path (4a) built and compiled but not run on Windows (Linux container).
- The spike uses the engine directly, with no EmbedPDF React plugins (no real UI yet).

## Known gaps / notes for later phases

- **Redaction (must fix before the feature ships):** EmbedPDF leaves images under the
  box, annotations over it, form field `/V` + widget appearance (which draws on top of
  the box), `/Info` and XMP. Plan: sanitize pass (remove page objects, annotations and
  fields; scrub metadata), then a qpdf rewrite, then the three-way leak scan
  (`tests/helpers/leak-scan.ts`). Flip each `it.fails` in `tests/redaction` to `it`.
- `extractText()` on zero-glyph pages returns uninitialized memory. Always use
  `src/engine/text.ts`.
- Always pass local WASM and `fontFallback: null` (`src/engine/pdfium.ts`).
- IRS forms are AcroForm + XFA hybrids.
- Dev machines need qpdf on PATH. CI and Playwright need `npx playwright install
chromium`, or `PW_CHROMIUM_PATH`.
- Delete `src/spike/` and the `#/spike` route when the real UI lands.
